# IOLSTAR Dashboard

Ürün, sipariş, fatura ve kapasite takip paneli. Sayfa GitHub Pages üzerinde statik olarak çalışır; veriler Supabase'de tutulur.

- Kurulum: `supabase/README.md`
- Bağlantı ayarları: `config.js`
- Giriş: tek hesap, şifre ile. Veriye yalnızca giriş yapmış kullanıcı erişir (`supabase/schema.sql`).
